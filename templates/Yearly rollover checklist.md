## Yearly rollover

### Areas

- [ ] For each area ([[Areas.base#Active]]): still active, or set to `closed`
- [ ] Move last year's history into `areas/<name>/archive/<year>/` from inside Obsidian, so links update

### Projects

- [ ] Done and cancelled projects are in `archive/` ([[Projects.base#Closed]])
- [ ] Paused projects: resume, or close them ([[Projects.base#Paused]])

### Recurring things

- [ ] Meeting series: start this year's note (`YYYY Title`) for each series ([[Meetings.base#All]])
- [ ] Cycle end checklist is done, and the next cycle note exists

### Knowledge

- [ ] Review hubs; prune or merge reference notes ([[Reference.base#Hubs]])
- [ ] Sources still `reading` are `done` or `abandoned` ([[Sources.base#Reading]])

### Housekeeping

- [ ] `inbox/` is empty; nothing is untyped ([[Untyped.base]])
- [ ] Run the kit's `install.sh` to pick up the latest kit; check `_kit/.kit-version`
