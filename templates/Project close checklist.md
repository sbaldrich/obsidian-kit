## Project close

### Decide the outcome

- [ ] Goal met, or stopped? Set the project `status` to `done` or `cancelled`
- [ ] Set `end` to the date it closed

### Resolve the loose ends

- [ ] Every task checkbox is `[x]`, `[-]`, or `[>]` with a new home
- [ ] Options are `chosen` or `rejected`
- [ ] Open meeting actions are done or moved

### Keep what is worth keeping

- [ ] Decisions that should be remembered are written down ([[Linked notes.base#Decisions]])
- [ ] Work: impact notes for the results; a story if it is reusable
- [ ] Lessons promoted to reference notes, linked to a hub ([[Reference.base]])
- [ ] Sources updated: `done` or `abandoned` ([[Sources.base]])
- [ ] Say thanks, or give feedback, to the people involved ([[Feedback.base#Open]])

### File it away

- [ ] Look at the linked notes once more for anything that should link elsewhere ([[Linked notes.base#By type]])
- [ ] Move the project folder to `archive/` from inside Obsidian, so links update
